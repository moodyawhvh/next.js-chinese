## 前置知识

本套文档假设你对 Web 开发已有一定了解。开始之前,建议你先熟悉:

- HTML
- CSS
- JavaScript
- React

如果你是 React 新手或想温故知新,推荐从[React 基础课程](/learn/react-foundations)开始,再学习[Next.js 基础课程](/learn/dashboard-app),边学边动手构建一个应用。
