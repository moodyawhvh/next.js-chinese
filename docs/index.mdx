## Next.js 是什么?

Next.js 是一个用于构建全栈 Web 应用的 React 框架。你用 React 组件构建用户界面,用 Next.js 获得额外的特性与优化。

它还会自动配置打包器、编译器等底层工具,让你专注于打造产品、快速上线。

无论你是独立开发者还是大型团队的一员,Next.js 都能帮你构建交互性强、动态、快速的 React 应用。

## App Router 与 Pages Router

Next.js 有两套路由:

- **App Router**:新一代路由,支持 Server Components 等 React 新特性。
- **Pages Router**:最初的经典路由,目前仍在维护和改进。

侧边栏顶部有一个下拉菜单,可以在 [App Router](/docs/app) 与 [Pages Router](/docs/pages) 文档之间切换。

### React 版本处理

App Router 与 Pages Router 对 React 版本的处理方式不同:

- **App Router**:内置使用 [React canary 版本](https://react.dev/blog/2023/05/03/react-canaries),其中包含全部稳定的 React 19 变更,以及在新的 React 正式版发布前、正由各框架验证的新特性。

- **Pages Router**:使用项目 `package.json` 中安装的 React 版本。

这种做法既保证 React 新特性在 App Router 中可靠工作,又为既有 Pages Router 应用保持向后兼容。
